# 学习流程、汉字编辑与手写画板设计

## 目标

在不改变现有单设备学习模型的前提下，完成四项改进：答题后立即进入下一个字；每个汉字可进入独立编辑视图；学习页面提供手写画板；学习进度既自动保存，也可导出和导入恢复。

## 范围

本次只修改现有单页应用，不引入新路由、账号系统、云同步或第三方画板依赖。笔迹只用于当次练习，不写入学习进度。导入导出使用本地 JSON 文件。

## 交互设计

### 答题后立即推进

- “会”“我会”“不会”“再学一下”四种判断操作都不再显示反馈卡。
- 点击后立即记录结果，并同步进入下一字。
- 如果当前字是本轮最后一个字，则直接进入总结页。
- “不会 / 再学一下”仍按现有规则把复习字退回新学习，或把学习字重新追加到本轮队列末尾。
- 到期复习保留“撤销上一步”；撤销恢复答题前状态和对应题目。

### 汉字编辑

- 家长中心的每张汉字状态卡都可点击，并有明确的“编辑”可访问名称。
- 点击后进入该字的专用编辑视图，而不是弹窗。
- 编辑视图展示汉字、当前学习阶段、阶段说明和当前有效组词。
- 家长可以添加包含目标字的 2 至 4 字组词，也可以隐藏当前推荐词或自定义词。
- “设为已掌握”和“设为新学习”为互斥操作。
- 两种状态切换都清零 `learningCorrect`、`stageStreak`，并将 `lastCountedDate`、`nextDue` 设为 `null`。
- 设为已掌握时：`stage = "MASTERED"`、`unfamiliar = false`。
- 设为新学习时：`stage = "LEARNING"`、`unfamiliar = true`。
- 保存仍通过现有顶层状态更新和 `localStorage` 自动持久化完成，不增加额外“保存”按钮。

### 手写画板

- 组词学习、单字认读、到期复习三个页面都显示可折叠的“练习书写”区域。
- 画板使用原生 `<canvas>` 和 Pointer Events，支持鼠标、触摸笔和手指。
- 画板提供“清空”按钮，并阻止书写手势触发页面滚动。
- 目标字改变或进入下一学习步骤时，画板自动清空。
- 笔迹不保存、不导出，不改变学习判断结果。
- 画板应有可访问名称和简短提示；不支持画布操作时，其他学习功能仍正常工作。

### 自动保存、导出与导入

- 每次答题、编辑组词、改变汉字状态或修改设置后，继续由现有 `localStorage` 自动保存。
- 家长中心“数据与恢复”区域增加“导出学习进度”和“导入学习进度”。
- 导出文件包含完整 `LiteracyState`，文件名带本地日期，例如 `识字小花园-学习进度-2026-08-01.json`。
- 导入只接受 JSON 文件。解析后校验状态版本、设置对象、汉字列表和关键字段类型。
- 校验失败时显示中文错误，不修改当前进度。
- 校验成功后先显示覆盖确认；确认后替换当前状态并自动保存。
- 用户取消文件选择或覆盖确认时，不修改任何状态。

## 代码结构

- `components/LiteracyApp.tsx`
  - 删除反馈卡、反馈状态和答题延迟定时器。
  - 将学习与复习答题改为同步推进。
  - 在三个学习视图中接入共用画板。
- `components/CharacterStatusBoard.tsx`

  - 状态卡变为可操作元素，只负责选择要编辑的汉字。
- `components/CharacterEditor.tsx`
  - 新组件，负责单字组词维护与状态切换界面。

  - 新增单字状态设置纯函数，统一重置相关字段。

- `app/globals.css`
  - 增加编辑页、可点击状态卡和响应式画板样式。

## 数据流

1. 用户操作组件。
2. 组件调用纯业务函数生成新的 `LiteracyState`。
3. `LiteracyApp` 更新顶层状态。
4. 现有 `useEffect` 将已更新状态写入 `kids-literacy:v1`。
5. 导出读取当前状态并生成下载文件；导入校验成功且确认覆盖后，再进入步骤 3。

## 错误与恢复

- 无效组词继续由业务函数过滤，不写入状态。
- 导入文件不可读、不是 JSON、版本不支持或结构不完整时，保留原状态并显示明确错误。
- Canvas 初始化失败只隐藏或禁用画板操作，不阻断答题。
- 导入覆盖前必须确认；现有“清空并重新开始”确认流程保持不变。
- 自动保存失败不引入新的阻塞流程，继续沿用浏览器存储能力；导出文件提供额外人工备份方式。

## 测试设计

### 自动化测试

- 学习答题立即推进，错误答案追加到队列后也立即换题。
- 复习答题立即推进，最后一题直接进入总结，撤销仍恢复上一题。
- 设为已掌握和设为新学习时，阶段及所有计数、日期字段正确重置。
- 导出后可通过导入解析得到等价状态。
- 非法 JSON、错误版本和缺失关键字段均被拒绝，且不产生替代状态。
- 汉字状态卡提供编辑入口，专用编辑视图接入组词与状态操作。
- 三个学习页面均接入手写画板，画板提供清空操作。

### 用户操作剧本

1. 从首页进入家长中心，搜索一个汉字并打开编辑页。
2. 添加一个合法组词，设为新学习，返回列表并刷新页面；确认修改仍存在。
3. 导出进度文件，改变该字状态，再导入文件并确认覆盖；确认状态恢复。
4. 从首页分别进入组词学习、单字认读和到期复习，展开画板书写并清空；确认换字后笔迹为空。
5. 点击“会 / 我会 / 不会 / 再学一下”；确认没有反馈停顿且立即换字，最后一题直接进入总结。
6. 失败恢复：选择非法进度文件时看到错误并保留当前进度；取消导入不发生变化。

## 验收标准

- 四种判断按钮均无反馈卡、无延迟定时器、立即推进。
- 每个汉字都能从家长中心进入编辑视图并修改组词与学习状态。
- 三种学习页面均能使用画板，画板在换字时自动清空。
- 所有状态修改自动保存；导出和导入恢复可用且不会被非法文件破坏。
- 单元测试、渲染测试、Lint、生产构建全部通过。
- 桌面与移动尺寸的真实浏览器操作剧本通过；若浏览器环境阻塞，需明确记录未通过项目及证据。
