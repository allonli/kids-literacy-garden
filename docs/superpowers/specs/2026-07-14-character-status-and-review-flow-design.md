# 汉字学习状态与复习流程优化设计

## 目标

为家长提供全部汉字的学习状态查询，并缩短孩子在复习环节中的操作路径。同时改善新学组词卡片的主按钮位置，使 iPad 和手机上的连续操作更顺手。

## 范围

本次包含：

- 在家长中心展示全部汉字的当前学习阶段。
- 支持按汉字搜索和按阶段筛选。
- 复习答题后自动进入下一个字。
- 调整新学组词卡片的底部操作区。

本次不包含账号、跨设备同步、历史趋势图、批量修改阶段或手动拖动汉字换组。

## 学习状态列表

### 分类口径

列表按汉字当前所在阶段分类，而不是按未来日期区间分类：

| 阶段值 | 用户看到的名称 |
| --- | --- |
| `LEARNING` | 待学习 |
| `DAILY` | 待复习 |
| `WEEKLY` | 每周复习 |
| `TWO_WEEKLY` | 每两周复习 |
| `MASTERED` | 已掌握 |

### 入口与布局

在家长中心新增“全部汉字学习情况”区域。区域顶部依次放置：

1. 汉字搜索框。
2. “全部”和五个学习阶段筛选标签，每个标签显示当前数量。
3. 匹配结果卡片网格。

默认选中“全部”。搜索和阶段筛选可以同时生效；搜索范围始终是全部已导入及家长新增的汉字。搜索忽略空格，一个输入框可输入一个或多个汉字，显示其中任意匹配的项目。没有匹配项时显示明确空状态。

### 汉字卡片

每张卡片显示：

- 汉字。
- 当前阶段中文名称。
- 当前阶段连续答对次数与升级目标；已掌握不显示升级进度。
- 下次复习日期；待学习显示“完成新学后安排”，已掌握显示“已完成全部阶段”。

列表仅用于查看，不在本次加入阶段编辑操作。

## 复习流程

复习环节移除反馈区中的“下一个”按钮：

- 答对后显示反馈约 700 毫秒，然后自动进入下一字。
- 选择“不会”或“再学一下”后显示拼音和组词约 1800 毫秒，然后自动进入下一字。
- 最后一字反馈结束后自动进入本轮完成页。
- 反馈期间两个判断按钮保持禁用，防止重复提交。
- 顶部继续保留“撤销上一步”。自动流转后，家长仍可撤销最近一次判断；撤销会回到对应复习字并恢复判断前状态。

自动跳转计时器在页面切换或组件卸载时必须清理，避免旧计时器改变新页面状态。

## 新学组词操作区

组词学习仍然需要孩子主动确认，因此保留“我学好了，下一个”：

- 操作区在组词卡片底部形成吸底区域，页面滚动时保持可见。
- “播放读音”为次按钮，“我学好了，下一个”为更醒目的主按钮。
- 小屏幕上主按钮占据更大宽度，并兼顾设备底部安全区。
- 卡片内容增加底部空间，确保操作区不遮挡提示和组词。
- 键盘焦点顺序仍为播放读音后进入下一字。

## 数据与组件边界

- 新增纯函数负责阶段名称、阶段目标、下次复习文案以及搜索筛选，便于独立测试。
- 新增学习状态列表组件，由家长中心传入 `state.items` 和学习设置；组件不直接修改学习数据。
- 复习自动流转仍由 `LiteracyApp` 管理，延续现有答题、反馈和撤销状态。
- 新学按钮只调整 `WordStudyCard` 的结构和样式，不改变学习队列逻辑。

## 测试与验收

### 自动测试

- 五个阶段映射到正确中文名称和数量。
- 搜索一个字、多个字、空搜索及搜索无结果。
- 阶段筛选与搜索组合生效。
- 各阶段进度和下次复习文案正确。
- 渲染结果包含状态区域及筛选控件。
- 复习反馈中不再出现“下一个”按钮。

### 用户操作剧本

1. 家长从首页进入“家长中心”。
2. 家长看到“全部汉字学习情况”、六个数量标签和汉字卡片。
3. 家长点击“已掌握”，确认只显示已掌握的字；输入汉字搜索，确认结果进一步缩小；清空搜索可以恢复。
4. 孩子回到首页进入复习，读字后点击“会”或“再学一下”。
5. 系统短暂显示反馈并自动进入下一字，不再要求点击“下一个”。
6. 若判断错误，家长点击“撤销上一步”恢复。
7. 进入新学组词页面，滚动页面，确认底部“我学好了，下一个”始终容易触达且不遮挡内容。
8. 失败恢复：无搜索结果时清空输入或切换“全部”；误判时使用“撤销上一步”；刷新页面后从已保存状态重新进入。
