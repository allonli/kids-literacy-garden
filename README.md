# 识字小花园

面向六岁儿童与陪学家长的识字网站。首页默认使用今日完整列表学习，也保留家长陪学流程；系统自动管理待复习、每周、每两周和已掌握阶段，并把进度永久同步到家庭设备。

## 已实现

- 导入《1识字更新总表.docx》的 649 个不同汉字，自动处理重复、跨阶段冲突和非汉字 `x`。
- 首页默认“列表学习”，暂时隐藏“孩子自主学习”入口，保留“家长陪学”。
- 今日列表一次展示全部待学习、到期复习及配置中的掌握抽查字，不受每轮取字数限制。
- 单击汉字，约半秒后记录学会并移出；双击或点击“不会”打开详情，将该字放到末尾，完成当前列表后集中复习。
- 新增手动选择的“本周末复习清单”，支持从清单、今日列表或详情添加和移出；每周重新选字。
- 本周末清单支持打印或另存为 PDF，使用 A4 六列字卡自动分页，仅打印清单标题、日期、字数和所选汉字。
- 新字和不熟悉字先学组词，再穿插进行单字认读。
- 每轮取字数、每字认读遍数、各阶段升级次数均可由家长设置。
- 家长中心可搜索全部汉字，并按待学习、待复习、每周、每两周和已掌握阶段查看进度。
- 家长中心支持删除单个汉字，确认后从当前账户移除该字资料、学习记录及今日和周末清单中的关联项。
- 详情默认隐藏拼音和组词，点击“显示拼音和组词”展开，再次点击可隐藏。
- 列表和详情均可编辑拼音、组词和当前学习状态；修改阶段会重新安排该阶段进度和复习时间。
- 手动编辑的拼音、组词优先于推荐内容；组词可留空清除，非空组词须为含目标字的 2–4 个汉字。
- 读音完成后点击“会”立即进入下一个字；新学组词保留容易触达的“我学好了，下一个”。
- 支持浏览器中文语音播放；播放期间锁定换卡操作，语音不可用时不影响学习。
- 使用六位家庭码登录，同一家庭的手机、平板和电脑自动同步。
- 同一家庭可添加多个学习账户；各自的学习进度、汉字编辑、今日列表和周末清单独立保存。
- 断网时继续保存到浏览器，联网后自动补传；旧设备不会覆盖服务器新版本。
- iPad 横竖屏与电脑浏览器自适应，主要按钮适合触控。

## 列表学习与周末复习

首页点击“开始列表学习”进入今天的完整清单。单击后稍等半秒，汉字从待认读列表消失；双击进入详情学习，点击“学完了，放到最后复习”返回。关闭弹窗也会保留这个不会的字。完成上方待认读字后，点击“集中复习不会的字”，直到清单完成。键盘 Enter/空格可标记学会，触屏也可以直接点“不会”。当天返回首页或刷新后，可继续剩余清单。

首页点击“本周末复习清单”，再点“添加汉字”搜索并手选汉字。详情和列表中的“加入周末”同步更新这份清单。“还需复习”会保留该字，“复习完成”会记录学习结果并移出。清单按北京时间的周一至周日划分，新周从空清单开始；它与学习阶段中的“每周复习”分别管理。

需要纸质复习时，在本周末清单点击“打印清单”，再在浏览器打印窗口选择打印机或“另存为 PDF”。打印稿使用 A4 纵向、每行六个汉字，字多时自动分页；不包含拼音、组词、学习状态或操作按钮。清单为空时打印按钮不可用，先添加汉字即可。打印或取消打印均不会改变清单和学习进度。

## 删除单个汉字

从首页进入“家长中心”，在汉字列表点击“删除”，或打开该中心的汉字详情后点击“删除这个字”。确认窗口会说明：该字的拼音、组词、学习进度和历史，以及今日列表、周末清单中的关联项，将从当前学习账户一并移除，其他账户不受影响。

取消确认会保留原内容；确认后该字从列表移除，页面显示删除提示，并自动保存和同步。等待“已永久保存”后刷新即可确认结果。断网时删除先保存在当前账户的本地缓存，联网后自动补传，也可点击同步“重试”。

需要再次学习时，在家长中心“添加新学的字”中重新添加，该字从头学习，已删除的编辑和学习记录不会恢复。允许删除最后一个字并保留空字库。删除入口仅放在家长中心，普通学习页面继续用于学习和复习。

## 添加与切换学习账户

登录后，首页的“当前学习账户”显示正在使用的账户，已有学习进度归属“原有账户”。点击“添加学习账户”，填写 1–20 个字符的名称，再点“添加并开始学习”，即可进入新账户。名称不能与已有账户重复，所有学习账户共用原来的家庭码。

新账户复制当前账户的字库、拼音、组词和学习设置，所有汉字从待学习开始，答题记录、今日队列和周末清单从空白开始。创建后，两个账户的编辑和学习操作分别保存；之后修改其中一个账户，不会同步改动另一个账户。

回到首页，用“切换学习账户”选择要学习的账户。学习页面会持续显示当前账户名称，返回首页后才能切换或添加。当前进度尚未同步时，这两个入口暂时不可用；恢复网络并等到“已永久保存”后即可继续。账户列表读取失败时点“重试读取”；添加时若无法确认结果，先取消并查看账户列表，已有新账户可直接选择。

## 数据保存

原有账户继续使用 `kids-literacy:v1` 做即时缓存。新增账户按账户 ID 隔离进度、同步版本和冲突快照，服务器使用 SQLite 做权威永久存储。

- 第一次升级时，必须先在原来学习的浏览器输入家庭码；看到“旧学习进度已永久保存”后才能登录第二台设备。
- 服务器为空而当前浏览器没有旧进度时，系统会阻止自动创建空进度。
- 本地修改会立即写入浏览器；服务器保存状态显示为“保存中”“已永久保存”或“网络断开，等待同步”。
- 每个学习账户的拼音与组词编辑、学习状态、当天列表队列和本周末清单均沿用上述永久同步机制；同一家庭的其他设备登录后可选择相同账户继续学习。
- 版本冲突时采用服务器最新进度，并把未接受的本地快照单独保留用于排查。
- 家长中心的“清空并重新开始”只重置当前学习账户，并同步到使用该账户的家庭设备，执行前会再次确认。

原有账户 ID 为 `default`，继续使用 `/api/progress` 和原来的 `progress` 表；新增账户使用 `/api/account-progress?accountId=<账户ID>` 和 `learning_accounts` 表。`/api/accounts` 提供账户列表与创建操作。新增表保留旧表及原有记录，旧设备迁移只适用于原有账户。

## 服务器配置

永久同步依赖 Node.js API 和 SQLite，不能部署为 GitHub Pages 纯静态站点。Vercel 可使用标准 Next.js 构建；正式数据目前部署在阿里云 `https://z.allon.me`。

服务环境文件 `/etc/kids-literacy-garden.env` 至少包含：

```ini
LITERACY_DB_PATH=/var/lib/kids-literacy/progress.sqlite
LITERACY_BACKUP_DIR=/var/backups/kids-literacy
LITERACY_FAMILY_CODE_HASH=scrypt$盐$摘要
```

生成家庭码时，先用安全随机数生成六位数字，再通过标准输入计算哈希，避免把明文家庭码写入服务器命令历史：

```powershell
$code = [System.Security.Cryptography.RandomNumberGenerator]::GetInt32(0, 1000000).ToString("D6")
$hash = $code | node scripts/hash-family-code.mjs
```

只把 `$hash` 写入环境文件；明文 `$code` 仅交给家长。环境文件权限设为 `600 root:root`。

## 备份与恢复

- 数据库固定在 `/var/lib/kids-literacy/progress.sqlite`，发布和回滚不能替换该目录。
- `kids-literacy-backup.timer` 每日运行一致性备份，文件保存在 `/var/backups/kids-literacy/`，保留 30 天。
- 发布前手动运行 `systemctl start kids-literacy-backup.service`，确认出现新的 `progress-YYYYMMDD-HHmmss.sqlite`。
- 恢复时先停止 `kids-literacy-garden`，用 SQLite `PRAGMA integrity_check` 校验选中的备份，再把现有数据库另存为应急副本，最后复制备份并恢复所属用户和权限。
- 应用回滚只切换 `/opt/kids-literacy-garden` 的程序版本，不回滚数据库。

对应 systemd 文件在 `deploy/`。正式服务监听 `127.0.0.1:17303`，由 nginx 提供 HTTPS。
